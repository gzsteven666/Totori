# Totori

一个本地自用的 macOS 文件格式转换器：菜单栏常驻，把文件拖进去，选个目标格式，转换完直接在访达里看。
参考 [Tangerine](https://apps.apple.com/) 的交互形态，转换后端全部换成系统 API 与开源命令行工具，中文界面。

- 版本：0.3.8 (29)
- 构建：不需要 Xcode，只用 Command Line Tools（`swiftc` + 手工组装 `.app`）
- 运行：Apple Silicon、macOS 13+；Releases 完整包内置 `ffmpeg`/`ffprobe`、`cwebp` 和 LibreOffice，无需 Homebrew。源码的普通开发构建使用本机工具。

## 两种用法

**① 拖拽花瓣**

在访达里选中文件 → 开始拖动（鼠标移动超过 8 点）→ 按住已设置的拖拽快捷键 → 光标处弹出花瓣 → 移到目标花瓣后松手执行。

拖放路径从拖放粘贴板取得文件；读取访达选中项的菜单路径可能需要系统 Automation 授权。未授权时仍可在主窗口选择文件，再使用「文件工具」或「滚轮」菜单。

图片、文档、音视频各自固定4—6个常用格式，可在设置的“管理常用格式”调整与上下移动。默认图片为PNG/JPEG/HEIC/WebP；每次呼出固定格式与顺序，不按频率排序，也不因拖动期间修改设置而换位。“更多”在松手后打开完整格式选择器，再明确点击转换；点取消不生成文件。主窗口仍保留全部格式。

**花瓣分三类**：默认 `⇧ Shift` 转换格式、`⌥ Option` 或 `⌘ Command` 文件工具、`⌃ Control` 文件动作。替代键任选其一即可。设置中显示完整名称、重复绑定优先级并可恢复默认；每类至少保留一个键。最后一个已启用按键保持选中颜色并显示锁，先添加替代键后才可取消。松开按键花瓣不会关闭，落点即执行；Esc 取消后，同次按住不会再打开花瓣；松开鼠标后可开始下一次拖动。方向键 + 回车也能选。

外观有「森林绿」（默认，森林凝胶）、「晨雾蓝」、「玻璃蓝」、「玻璃绿」四种，可在设置里切换。主窗口、工具面板与轮盘跟随系统明暗外观。

**② 菜单栏**

菜单栏可打开主窗口、文件浮窗与设置。主窗口的「文件工具」菜单可使用裁剪、标注、压缩、修剪等工具；「滚轮」菜单可打开三种轮盘，格式滚轮快捷键为 ⌘⇧F。主窗口有文件时优先使用已导入文件，否则读取访达选中项。浮窗支持拖入、拖出、标题区移动、添加文件、钉住与空格预览。成功拖到外部目标后移除对应暂存条目；取消、拒收或拖回浮窗时保留，磁盘原文件不删除。

轮盘输出写在源文件旁边；主窗口可选择源目录或指定目录。同名自动加序号。工具完成后显示文件、位置和「在访达中显示」；压缩显示实测节省字节，没有变小时保留原件并说明。

## 批量任务、简介与对比

主窗口空态集中提供导入入口；有文件后收为紧凑工具栏。主按钮明确显示“转换全部 N 个”；列表选中后另有“转换所选 N 个”。两个入口均按当前设置开始新批次，更新本次状态，磁盘上的原件与已有输出保留。所选批次失败或取消后，主操作优先重试/继续原范围；其余文件保留待转换。选中方框与完成圆形勾标记分开。处理期间锁定输出设置。

支持调整质量的输出格式旁提供“本次质量”：默认、最小体积、均衡、最好画质。覆盖值只用于当前模型内的新批次，不改写设置中的全局默认；清空后恢复默认。普通图片转换不缩小像素尺寸。PNG、无损音频、文档、压缩包以及使用固定编码参数的格式不显示质量入口。完成行直接显示源/目标格式、前后大小与变化比例；体积减少用绿色，增加/相同用中性色，对比窗口采用相同规则。

主窗口支持取消当前批次、只重试失败项、继续取消后未完成项。重试沿用原批格式、质量和输出目录，不重复转换已成功文件。滚轮与压缩任务的进度浮层也可取消，失败结果提供重试入口。外部编码进程接收终止请求；ImageIO 等系统同步处理在当前步骤结束后协作停止。取消/失败的本次暂存输出会清理，已完成结果保留。

主列表、浮窗和输出结果显示异步文件简介：图片为格式、方向校正后的像素与大小；视频增加时长；音频显示时长且不把封面当视频；PDF 显示页数。普通文档和压缩包显示可核实的格式、体积，压缩包不自动解包。读取不到的字段不填 0。

“对比结果”使用紧凑信息栏，文件操作收进菜单。图片支持并排、共同缩放与滚动；同像素尺寸的图片可拖动分界线对比，按住查看原图或用复选框锁定原图。超过最长边 4096 的图片使用有提示的缩略预览，动图显示第一帧。非图片可通过菜单快速查看或打开两份文件。

主列表与浮窗均支持 ⌘ 点击多选、⇧ 点击范围选择、⌘A 全选、空格快速查看和 Delete 移除引用；原文件保留。浮窗另有 ⌘Z 撤销移除，方向键换项后会滚到所选文件。

浮窗提供图片缩略图、视频首帧和网格/列表切换。视图模式在重启后保留，列表适合长文件名；简介保留图片分辨率、视频时长与文件大小，悬停可查看完整名字和路径。缩略图只读取内容，不改动原文件。

浮窗成功拖出后在底部显示“已拖出 N 个”，旁边直接提供“撤销”；取消、拒收和拖回自身保留条目，不伪报交付。底部可手动切换紧凑/展开，宽度328不变，高度260/440；启动恢复此偏好，切换保持顶边并夹回当前屏幕。文件拖动会话中拒绝切换尺寸。

浮窗“撤销移除”覆盖成功拖出、手动移除和清空，最多保留 20 步本次运行历史；只恢复仍存在的文件引用，不移动或删除原件。展开位置在关闭/重开和重启后恢复，屏幕变化时夹回可见区域；边条位置不覆盖展开位置。

## 构建与运行

```bash
./build.sh                       # 产出 Totori.app
open "Totori.app"               # 启动（菜单栏出现图标，同时打开主窗口）
"Totori.app/Contents/MacOS/XiaoJuConvert" --selftest   # 跑转换自检
```

`build.sh` 在临时目录编译、组装资源并验证签名，通过后才替换正式 App。优先使用已有本地签名身份，缺失时采用 ad-hoc；旧 App 留在 backups。编译或签名失败不删除旧版，构建锁阻止同时发布。

## 能力矩阵

| 输入 | 可输出 | 实现 |
| --- | --- | --- |
| png / jpg / heic / tiff / bmp / gif / webp / avif | png / jpg / heic / tiff / webp / pdf | ImageIO（`CGImageDestination`）；WebP 使用 `cwebp`，按档位设置质量，保留原像素尺寸 |
| doc / docx / rtf / html / txt / md / odt / pages / epub 等 | pdf / html / txt / rtf / docx / odt | LibreOffice headless 优先（`soffice --convert-to`），失败退 `cupsfilter`（PDF）或 `textutil` |
| mp4 / mov / mkv / webm / avi / mp3 / flac / wav / m4a / ogg 等 | mp4 / mov / webm / gif / mp3 / m4a / wav | `ffmpeg`：视频走 `h264_videotoolbox`（硬编）、WebM 走 `libvpx-vp9`+`libopus`、音频 `libmp3lame`/`aac`/`pcm_s16le`，进度用 `-progress pipe:1` 实时解析 |
| zip / tar / gz 等 | zip | `ditto -c -k --keepParent` 外层打包，原扩展名保留为 `.tar.zip` 等 |

**已知行为**：同名文件自动加序号（`文件名 2.png`），不会覆盖；批量转换时按队列串行执行，进度条是整体进度。

## 自检覆盖

`--selftest` 生成合成样本，覆盖 26 项：图片、文档和音视频转换，同名避让、标注、修剪、压缩、二维码、PDF 合并与拆页等。本机 26 项通过；这不代表所有输入文件或所有系统版本均已验证。

新增 `--probe-favorites`（常用顺序、呼出快照、更多分流）及 `--probe-shelf-enhancements`（浮窗反馈、紧凑模式与拖动状态）。

已有 `--probe-task-options`（真实写出范围、质量快照、取消/重试）与 `--probe-output-summary`（体积摘要语义）。

专项入口包括 `--probe-paw-tick`、`--probe-menu-mode`、`--probe-assets`、`--probe-shelf`、`--probe-theme` 等。独立验收还检查 8 种 EXIF 方向像素、精确修剪时长、压缩收益与并发命名。声明最低 macOS 13，当前实际验收机器为 macOS 27.2。

## 与原版 Tangerine 的差异

| 项 | Tangerine | Totori |
| --- | --- | --- |
| Office → PDF | 自带 JDK + Apache POI + PDFBox | 完整包内置 LibreOffice headless |
| `.pages` 写入 | 自带 `PagesWriter.js`（IWA+Snappy+protobuf） | 未实现（见报告拉伸项） |
| 元数据清理 | 自带加固版 ExifTool（`tangerine_metadata.pl`） | ImageIO 重写，能力较弱 |
| 付费 | RevenueCat 订阅 | 无 |
| 界面 | 英文 | 中文 |
